Класс «Товар» содержит следующие обязательные поля:
название товара (массив символов типа char, название содержит не более 30 символов)
стоимость товара
срок годности (задается тремя целыми числами — дата, месяц, год)
Класс «Магазин» содержит следующие обязательные поля:
название магазина (массив символов типа char, название содержит не более 30 символов)
город (массив символов типа char, содержит не более 20 символов)
количество товаров
массив объектов типа «Товар» (использовать идентификаторы на товары нельзя, память выделяется динамически, размер массива во время выполнения программы не меняется)
количество доступных экземпляров товаров (целочисленный массив типа unsigned, память выделяется динамически, размерность совпадает с количеством товаров — в массиве хранится количество экземпляров i-го товара, размер массива во время выполнения программы не меняется)
Формат входного файла «products.txt»:
В первой строке содержится количество товаров
Далее в следующих строках через пробел указаны:
название товара
стоимость товара
три целых числа, задающих срок годности
Примечание: предполагается, что товаров с одинаковыми названиями в файле гарантировано нет
Формат входного файла «stores.txt»:
Первая строка — количество магазинов
Далее для каждого магазина в отдельной строке указано:
название
город
количество товаров
далее через пробел перечисляются пары названия товара и количество экземпляров, конкретного товара (строка и целое число)
Примечание:
если при обработке файла встречается магазин с названием, которое уже встречалось ранее, программа должна выдать соответствующее сообщение (данный магазин повторно добавлять не нужно);
если хотя бы один из товаров, указанных в файле «stores.txt», отсутствует в файле «products.txt», программа должна вывести сообщение об ошибке  (соответствующий магазин не обрабатывать и не добавлять в массив);
если у одного магазина указаны два или несколько товаров с одинаковыми названиями, то количество экземпляров товаров суммируется
Программа должна обрабатывать следующие запросы, используя оператор switch (для выхода из программы используется запрос с кодом 0):
Вывести подробную информацию обо всех товарах 
Вывести подробную информацию обо всех магазинах
Вывести стоимость всех товаров для указанного магазина (стоимость просроченных товаров выводить не нужно)
Вывести количество экземпляров указанного товара, доступных в указанном городе (количество просроченных товаров учитывать не нужно)
Вывести магазин, в котором доступно наибольшее количество экземпляров товара
